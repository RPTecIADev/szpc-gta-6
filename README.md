## 🚀 O Projeto

Este repositório guarda o código-fonte de uma página interativa projetada para capturar a atenção do usuário. O desenvolvimento focou em performance, semântica e interatividade, utilizando tecnologias front-end puras. O resultado é uma interface fluida, com manipulação de DOM para exibição do trailer oficial em modais dinâmicos.

### 🌌 Principais Funcionalidades

- **Design 100% Responsivo:** O layout se adapta como água, seja em monitores ultrawide ou telas mobile.
- **Estética Cyber-Vibrante:** Paleta de cores contrastante, com toques de azul elétrico e verde neon, trazendo um ar futurista e dinâmico.
- **Modal de Mídia Interativo:** Acionamento do trailer do jogo em um modal overlay com botões de fechar customizados e pausa automática.
- **Hover Effects & Transições:** Botões e links que respondem ao usuário com transições suaves e estilizadas.

## ⚙️ Como Executar na sua Máquina

Para rodar este projeto localmente para modificações ou estudos, é super simples. Nenhuma instalação de pacote é necessária!

1. **Clone este repositório:**

